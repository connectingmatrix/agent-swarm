# @connectingmatrix/agent-swarm final runtime contracts

This file is generated by the final process-monitor / project / nodes / workflow-AI / Giga-agents hardening pass.

## Ownership

- multi-agent orchestration across 10-100 agents
- awareness of core, advanced, and giga agent systems
- swarm task process tracking and abort

## Public API contracts

- `AgentSwarm.bindSystems({ aiAgents, advancedAgents, gigaAgents })`
- `AgentSwarm.getSystems()`
- `AgentSwarm.run(input,options)`
- `AgentSwarm.abort(processId,reason)`
- `AgentSwarm.onProgress(handler)`

## Routes / launcher

- `GET /agent-swarm/health`
- `POST /agent-swarm/run`
- `POST /agent-swarm/abort`
- `GET /agent-swarm/launcher`

## Notes

- The swarm is thin orchestration; individual agent capability stays in the owning package.
